# 中壢污水大作戰

本版本包含首頁、Stage 1～9 與結尾關卡，可直接開啟 `index.html` 執行；若瀏覽器限制本機資源，請改用本機網頁伺服器開啟。

## 目前功能

- 首頁：背景音樂預設開啟；左上角提供「官方網站」與「介紹影片」按鈕，點擊有回饋音效。
- Stage 1：呈現中壢環境的過去與現在，角色與對話依序入場。
- Stage 2：點選四個區域查看污染來源；階段標籤與副標已依頂框重新置中。
- Stage 3：阿澤、小白與對話依序入場，角色持續自然待機擺動。
- Stage 4：配置工作人員完成四區工程，也可使用右下角共用「下一階段」按鈕前往 Stage 5；底部大型對話框已移除，遊戲地圖完整顯示。
- Stage 5：提供便民服務、污水處理流程、接管分期、詳細工期搜尋四個主題。
- Stage 6：依序點擊五個工程位置，查看說明會與簽署、施工現場放樣、改管佈設、銜接與試水、化糞池清理；完成後可單擊前往下一階段，未完成時也可快速連按三下略過並進入 Stage 7。
- Stage 7：說明人孔蓋堵塞的 24 小時通報服務，畫面元件依序滑入並漸顯。
- Stage 8：進行「什麼可以丟馬桶？」生活物品分類遊戲；每題需在 3 秒內選擇馬桶、水槽、垃圾桶或水溝。
- Stage 9：呈現「截、濾、避、分」四項用戶維管原則，完成後進入結尾關卡。
- 結尾關卡：點選中壢四區依序觀看各三張照片；四區全部收集完成後自動播放乾淨河川影片，播放結束返回首頁。

## 共用 UI

- Stage 1～9 與結尾關卡全面統一使用 `assets/common/all_ui.png` 外框。
- 所有階段的返回、下一階段與音效按鈕，統一使用 `previous_ui.png`、`next_ui.png`、`sound_ui.png`。
- 共用素材以 `object-fit: contain` 顯示，維持原始比例，不做非等比拉伸。

## Stage 8 分類遊戲

- Stage 7 右下角「下一階段」可直接進入 Stage 8；左下角可返回 Stage 7。
- 進入 Stage 8 時會先顯示簡短玩法說明，按下「開始遊戲」後才開始第一題與 3 秒倒數。
- 使用 `assets/stage8/` 的背景、角色、題目框、計時／分數框、四個去向卡與 8 個生活物件素材，全部維持原始比例。
- 每局 10 題，每題倒數 3 秒；答題後顯示約 0.7 秒的正確、錯誤或逾時提示，並播放各自的提示音。
- 適量可溶衛生紙的正確去向為馬桶；尿布、油脂、塑膠袋、衛生棉、濕紙巾、頭髮及廚餘在四個選項中應選垃圾桶。
- 正確作答會降低堵塞值，錯誤或逾時會提高堵塞值；百分比與量表指標會同步更新。
- 完成 10 題後才會解鎖右下角「下一階段」；離開 Stage 8 時會停止所有倒數與回饋計時器。
- 未完成遊戲時，快速連按右下角「下一階段」三下也可略過並進入 Stage 9。
- 階段標籤、主標與副標已向下／向右校正；完成狀態文字也已依指定位置右移。
